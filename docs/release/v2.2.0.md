# cli-forge v2.2.0

Security fixes for the auth seam and for what parse errors print, plus a few
small additions. No 2.1 program needs editing to upgrade.

## Security

- **A gate on a command group covers its subcommands.** With the `auth` feature,
  `requires_auth` on a group was only checked when the group itself was invoked,
  so its subcommands ran without the hook being asked. Every gated command on the
  path is now checked, root first.
- **Help for a command the user may not run is not shown.** The gate now runs
  before `--help` and `prog help <command>`. `--help` on a gated command is
  refused as `Unauthorized`, `prog help <command>` shows the app help, and
  `App::command_help` returns `None`.
- **Environment values are never quoted in parse errors.** A bad value from
  `Arg::env` is reported as `invalid value in $NAME`, and `subject()` is `$NAME`.
- **Control characters from the command line no longer reach the terminal** in
  a parse error. They are shown in caret notation; `subject()` keeps the raw text.
- **Hyperlink URLs are percent-encoded** where they hold control characters, in
  `Style::link` and the markup `<link=URL>` tag, so a URL cannot end the link
  sequence early.
- **"Did you mean" never names a hidden or unauthorized command.**

## Fixed

- After `--`, a name that is empty, starts with `-`, or contains `/` or `\` is no
  longer handed to the external hook. It is reported as an unknown command or
  flag.
- `-vvv` no longer allocates once per `v`.

## Added

- `Arg::sensitive(true)`: the value is never quoted in a parse error and shows as
  `<redacted>` in `Debug` for `Matches`.
- `text::escape_markup`, for putting text from elsewhere into a markup string.
- `Command::hide` and `Arg::hidden`, so both names work on both types.

## Changed

- For an invalid value from the environment or a sensitive argument,
  `ParseError::subject()` is the argument as written, not the value.
- With `auth`, a refused gated command is reported as `Unauthorized` before any
  other error at its level or below.

## Installation

```toml
[dependencies]
cli-forge = "2.2"
```
